# ZPet Device Manager

Connect your ZPet device via USB to manage and update firmware.

**[👉 Open Device Manager](https://iminaine.github.io/zpet_web/)**

## Features
- Connect device via USB
- View and edit pet stats
- Update firmware safely
- Backup your pet data

## Browser Support
- Chrome ✅
- Edge ✅
- Opera ✅
- Firefox ❌ (no Web Serial)
- Safari ❌ (no Web Serial)
